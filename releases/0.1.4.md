# FlashCard 0.1.4

## Highlights

- Fix vault rescans that could report `0 cards in 0 notes` while another scan was still running. A new rescan request now waits for the active pass and schedules a fresh pass when needed.
- Add regression coverage for root-level card files under the configured `FlashCard Book` folder, bullet-prefixed `Question :: Answer` lines, and overlapping scan requests.
- Improve automatic-generation safety around template folders and unresolved Templater/Core Templates placeholders. Template-folder exclusion can be configured in Settings.
- Add a release-metadata regression test to catch mismatches between `package.json`, `manifest.json`, and `versions.json`.
- Add CodeQL analysis, Dependabot update checks, contributor guidance, security-reporting guidance, issue templates, and architecture/testing/release documentation.

## Compatibility

- Requires Obsidian **1.7.2 or newer**.
- Local-first: FlashCard does not require an account, API key, or remote AI service.

## Installation files

This release includes `main.js`, `manifest.json`, and `styles.css`.

## Upgrade note

After installing 0.1.4, run **FlashCard Book: Rescan vault for cards** once if your existing notes previously showed zero cards. Keep your original notes and card files; this release does not require deleting or recreating them.
