# FlashCard 0.1.6

## Security

- Harden HTML-to-Markdown conversion for imported Anki and other HTML-bearing card data.
- Parse HTML with the browser's DOM parser in Obsidian rather than removing tags with a broad regular expression.
- Drop script, style, and embedded active-content elements; preserve only supported Markdown formatting.
- Escape entity-decoded text so encoded markup cannot be re-emitted as active HTML.
- Ignore image event-handler attributes, allow only HTTP(S) external image links, and reject unsafe media paths.
- Add regression tests for encoded tags, script/style content, JavaScript image URLs, malformed tag fragments, invalid entities, and path traversal.

## Maintenance

- Align the npm lockfile version with the plugin version and test that package, lockfile, manifest, and Obsidian compatibility metadata stay consistent.

## Compatibility

- Requires Obsidian **1.7.2 or newer**.
- Existing card data and review history are preserved. Source notes are not rewritten by HTML conversion.

## Upgrade

Update FlashCard through Obsidian Community Plugins after the directory lists 0.1.6. If you import external HTML or Anki data, use the latest release rather than relying on an older importer.
