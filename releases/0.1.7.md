# FlashCard 0.1.7

## Focused practice by source note

- Add a **Practice note…** action to the Decks screen.
- Search indexed source notes by note title or full path, then start a review containing only cards from the selected note.
- Show each source note's full path and its total, New, Learning, and Due counts before starting.
- Keep the existing folder-based deck tree unchanged. Notes in one folder can now be practised individually without moving files or restructuring decks.
- Exclude internal card-storage files and missing source notes from the picker.

## Compatibility

- Requires Obsidian **1.7.2 or newer**.
- Uses the existing review queue and scheduling logic; it does not create duplicate cards or change the source notes.

## Use

Open **FlashCard Book → Decks → Practice note…**, search for a subject such as `Microeconomics`, and select the matching note. Review is then limited to that source note.
