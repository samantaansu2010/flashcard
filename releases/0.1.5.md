# FlashCard 0.1.5

## Fixes

- Fix automatic extraction of explicit separator cards in ordinary notes selected for automatic generation. Enabled separators such as `Question :: Answer` now work in eligible notes tagged with `#flashcard` or selected by the configured folder scope.
- Make **Preview cards of the current note** recognise configured separators in ordinary notes as well.
- Keep internal FlashCard folders whose names begin with an underscore, such as `_exports` and `_media`, out of ordinary-note indexing.
- Add regression coverage for tag-scoped notes containing bullet-prefixed separator lines.

## Compatibility

- Requires Obsidian **1.7.2 or newer**.
- Source notes are not rewritten. Automatically generated cards are indexed from the note and use the note's folder as their generated deck.

## Upgrade

After installing 0.1.5, run **FlashCard Book: Rescan vault for cards**. A note in your selected automatic-generation scope that contains lines such as `What is the chemical symbol for gold? :: Au` should now generate cards, provided the **Separator cards** rule and `::` separator are enabled.
